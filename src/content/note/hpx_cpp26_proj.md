Spent a few months contributing to **The HPX Project**, focusing on C++26 reflection-based to automate boilerplate for user-defined types that helps with serialization. Handles private members, polymorphic types and more `B-)`

Worked alongside Prof. Hartmut Kaiser, merged PRs for:

- Extended serialization support for STL associative containers ([PR 6864](https://github.com/TheHPXProject/hpx/pull/6864)).
- Ideated and implemented the P2996 based reflection-based auto-serialization support ([PR 6859](https://github.com/TheHPXProject/hpx/pull/6859)).
- Did some code reviews for other reflection-related proposals and implementations ([PR 7039](https://github.com/TheHPXProject/hpx/pull/7039), [PR 7016](https://github.com/TheHPXProject/hpx/pull/7016)).

A great experience overall!
